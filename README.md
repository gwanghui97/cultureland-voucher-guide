# 문화상품권 사용 길잡이

> Y-AI 메이커톤 2026 · 컬쳐랜드 사전 미션 제출작
> "사용처 확인부터 상품권 사용 방법까지, 하나의 이용 흐름으로"

**사용하고 싶은 곳**과 **내가 가진 상품권 종류**를 알려 주면, 그 조합에 맞는 사용 경로를 안내하는 모바일 웹 시제품입니다.
가능 여부, 수수료, 제한 사항, 단계별 사용 방법을 한 흐름으로 보여 줍니다.
이 시제품은 컬쳐랜드 앱에 들어갈 기능을 제안하는 **제안 화면**입니다. 실제 결제, 충전, 회원 계정과는 연동되어 있지 않습니다.

## 해결하려는 문제

이벤트로 모바일 문화상품권을 받은 20대 대학생이 네이버쇼핑에서 상품권을 쓰려고 합니다.
"번호만 넣으면 결제되겠지"라고 생각하지만, 실제로는 아래 과정을 거쳐야 합니다.

1. 상품권과 교환권을 구분합니다.
2. 컬쳐캐쉬로 충전합니다.
3. Npay 포인트로 전환합니다. 이때 수수료가 붙습니다.
4. 결제합니다.

사용자가 막히는 지점은 세 곳입니다. 상품권 종류를 구분하지 못하고, 등록·교환 단계에서 멈추고, 전환 수수료를 미리 알지 못합니다.

핵심 문제는 사용처가 부족한 것이 아닙니다. **내 상품권을 어디서, 어떤 순서로 써야 하는지 한눈에 알 수 없다는 점**입니다.

## 이용 흐름

```
① 사용처 검색 → ② 상품권 종류 확인 → ③ 가능 여부·조건 → ④ 맞춤 사용 방법
                     └─ 잘 모르겠어요 → 구분 도우미(예시 카드, PIN 입력 없음)
```

- **① 사용처 검색**: 사용처 이름이나 문장("네이버에서 문상 쓸 수 있어?")을 입력하거나 카테고리 칩을 누릅니다. 지원하지 않는 사용처는 "결과 없음"과 공식 사용처 안내로 연결합니다.
- **② 상품권 종류 확인**: 통합형 컬쳐랜드상품권, 오프라인 전용 상품권, 교환권, 지류·온라인 문화상품권 중에서 고릅니다. 종류를 모르면 구분 도우미를 엽니다.
- **③ 가능 여부·조건**: 사용 가능·교환 먼저·불가·미확인 배지, 조건, 결제 제한 품목, 수수료 계산기, 출처를 보여 줍니다.
- **④ 맞춤 사용 방법**: 단계별 체크리스트를 보여 줍니다. CU는 결제 방법 탭을 나눕니다. 오류가 났을 때의 대처와 다음 행동도 안내합니다.

## 지원 시나리오 (사용처 2곳 × 상품권 4종)

| | 통합형 | 오프라인 전용 | 교환권 | 지류·온라인 문화상품권 |
|---|---|---|---|---|
| **네이버쇼핑** (온라인) | 컬쳐캐쉬 충전 → Npay 전환(수수료 6%) → 결제 | 이 경로 불가 → **CU에서 쓰기**로 연결 | 교환소에서 교환 → 받은 종류 다시 선택 | Npay 전환 서비스 종료 → 다른 사용처 안내 |
| **CU** (오프라인) | 상품권 바코드 / 앱 바코드 | 상품권 바코드 | 교환소에서 교환 → 받은 종류 다시 선택 | 미확인 → 발행사 확인 |

## 정확성: 공식 출처와 검증

모든 정책 카드에 `출처 · 확인일 2026.11.11 · 원문 보기`를 표시합니다.
원문끼리 내용이 다르면 **과거 공지와 차이** 배지를, 원문으로 확인하지 못했으면 **미확인** 배지를 붙입니다.

| 내용 | 출처 | 상태 |
|---|---|---|
| Npay 전환 수수료 6%, 최소 1,000원, 본인인증, 명의 일치, 취소 불가, 당일 한도 | [컬쳐랜드 Npay 전환](https://www.cultureland.co.kr/conversion/naverpay_bridge.do) | 확인 |
| 2024-01-01부터 6.5%로 변경한다는 공지 | [컬쳐랜드 공지 2023-12-21](https://m.cultureland.co.kr/tgl/noticeBoard.do?NoteID=2083) | 과거 공지와 차이 |
| 컬쳐랜드상품권 충전 가능, 지류·온라인문화상품권 충전 불가, 교환소 절차 | [컬쳐랜드 FAQ](https://m.cultureland.co.kr/cstm/faqMain.do) | 확인 |
| CU 바코드 결제, 서비스 불가 항목(담배·택배·상품권·복권·T머니충전), 오프라인 전용 상품권 충전 불가 | [컬쳐랜드 상품권 도움말](https://www.cultureland.co.kr/customer/help/serviceHelp.do?class1=1&class2=1) | 확인 |
| 앱 바코드 결제 절차 | [컬쳐랜드 앱 바코드 도움말](https://www.cultureland.co.kr/customer/help/serviceHelp.do?class1=2&class2=7) | 확인 |
| 문화상품권 Npay 포인트 전환 제휴 종료(2025-03-31) | [SBS Biz 보도](https://biz.sbs.co.kr/amp/article/20000224095) | 미확인(공식 공지 원문은 로그인이 필요해 열지 못함) |

**검증하면서 고친 사례**
- 검색 요약에는 Npay 전환 수수료가 6.5%로 나왔습니다. 원문을 직접 열어 보니 6%였습니다. 6.5%는 2023년 공지에 나온 수치였습니다.
- 18자리 문화상품권의 "Npay 전환 6.5%, 일 20만·월 50만 원" 안내는 이미 종료된 서비스의 정보였습니다. 계산기와 수치를 빼고 "전환 서비스 종료"로 바꿨습니다.
- 원문에 없는 문구를 지웠습니다("바로충전 링크", "알림톡/문자", "헌혈기념품 예외"). CU 제한 품목은 원문 표현 그대로 바꿨습니다.

## 앱 적용 구상

- **진입 위치 1**: 컬쳐랜드 앱 홈의 컬쳐캐쉬 아이콘 영역(바코드 결제·전환·쇼핑…)에 "사용처 찾기"를 추가합니다.
- **진입 위치 2**: 상품권을 받은 직후 화면(알림톡이나 바로충전 랜딩)에 "이 상품권 어디서 쓰지?"를 둡니다.
- 정책 데이터(`data.js`)와 화면을 분리했습니다. 수수료나 제휴처가 바뀌면 데이터 파일만 고치면 됩니다.

## 구현 범위

| 이번에 구현 | 구현하지 않음 |
|---|---|
| 사용처 검색, 별칭 키워드 매칭 | 실시간 AI 자연어 질의응답 |
| 상품권 유형별 분기(8개 조합) | 실제 PIN 인증 |
| 단계별 사용 방법, 수수료 계산 | 실제 충전·전환·결제 |
| CU 바코드 결제 안내 화면 | 실시간 잔액·가맹점 연동 |
| 공식 출처·확인일·검증 상태 표시 | 컬쳐랜드 앱 내부 연동 |

## AI 활용

- **기획·조사**: 생성형 AI로 사용자 시나리오와 막히는 지점을 정리하고 공식 정보를 조사했습니다.
- **설계·구현**: Claude Code로 설계 문서, 구현 계획, 코드, 시험을 만들었습니다. 역할별 서브에이전트(구현, 시험, QA, 사실 확인)가 나눠서 맡았습니다.
- **검증**: AI가 만든 정보는 공식 원문과 하나씩 대조했고, 맞지 않는 것은 위 "검증하면서 고친 사례"처럼 고쳤습니다. 화면의 자연어 검색은 AI가 아니라 별칭 키워드 매칭이며, 화면에도 그렇게 표시합니다.

## 실행

Node 22 이상이 필요합니다. 모든 명령은 `web/` 폴더에서 실행합니다.

```bash
cd web
npm install
npm run dev      # http://localhost:5173
npm test         # node:test 단위 시험
npm run build    # dist/ 생성
```

배포는 Vercel에서 프로젝트 Root Directory를 `web`으로 지정하면 됩니다(Vite 정적 사이트). 환경 변수와 API 키는 필요 없습니다.

## 에셋과 권리

로고와 캐릭터는 컬쳐랜드가 이 미션용으로 제공한 에셋에서 추출했습니다. 브랜드 권리는 (주)한국문화진흥에 있습니다.
원본 에셋 압축 파일과 미션 안내 PDF는 저장소에 포함하지 않습니다.
화면의 예시 번호, 잔액, 충전 화면은 모두 `시연용` 가상 데이터입니다.
